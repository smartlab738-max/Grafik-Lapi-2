Pengaturan Penyimpanan GitHub

Tujuan sudah otomatis: smartlab738-max/Grafik-Lapi-2 → rekap-data/rekap-listrik.json. Anda tidak perlu mengisi path.

Token hanya disimpan dalam memori selama tab terbuka, tidak ditulis ke HTML, JSON, atau penyimpanan lokal. Gunakan izin Contents: Read and write pada repository Hormon-Oktober. Cabut token lama yang pernah dibagikan.

Data 2025–2026 berasal dari file Rekap Laporan Mingguan Listrik; tahun baru akan muncul ketika ada input bertanggal tahun tersebut. Tahun berjalan mengikuti jam perangkat yang lazimnya disinkronkan melalui NTP, bukan akses NTP langsung dari browser. Periksa nilai yang tidak wajar sebelum menyajikan total bulanan sebagai final. Jika beberapa meter mencakup submeter lain, jangan jumlahkan semuanya sebagai total konsumsi fasilitas.
